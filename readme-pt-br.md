# 💰 Fintech – Organizador de Finanças Pessoais

Este repositório contém um **projeto acadêmico de Fintech** desenvolvido como parte de um trabalho de faculdade.  
O projeto é dividido em **cinco fases**, cada uma representando um estágio diferente de desenvolvimento, evoluindo de uma página simples de front-end até uma aplicação full stack completa.


## 🚀 Objetivo do Projeto

O principal objetivo é demonstrar a **evolução progressiva da arquitetura de software e das tecnologias**, incluindo HTML, CSS, JavaScript, Java com POO, herança, arquitetura DAO, integração com banco de dados Oracle e desenvolvimento full stack moderno.

---

## 🧱 Estrutura do Projeto
```bash
|── fase1-simple-page/        # Página web básica usando HTML, CSS e Bootstrap
|── fase2-java-classes/       # Classes Java com métodos simulados (System.out.println)
|── fase3-java-Inheritance/   # Classes totalmente implementadas usando herança + classe de teste
|── fase4-DAO/                # Arquitetura DAO
└── final-project/            # Aplicação Full Stack
```
Cada pasta representa uma fase independente do projeto e pode ser analisada separadamente.

---

## 📂 Visão Geral das Fases

### 🔹 Fase 1 – Página Simples
**Pasta:** `fase1-simple-page`

- Página inicial simples de front-end
- Apresentação inicial da ideia da fintech
- Foco em layout e conceitos básicos de interface do usuário

**Tecnologias:**
- HTML
- CSS
- Bootstrap

---

### 🔹 Fase 2 – Classes Java
**Pasta:** `fase2-java-classes`

- Criação das principais classes Java do backend
- Foco em conceitos de programação orientada a objetos:
  - Encapsulamento
  - Atributos e métodos

**Tecnologias:**
- Java

---

### 🔹 Fase 3 – Herança em Java
**Pasta:** `fase3-java-inheritance`

- Refatoração e extensão das classes do backend
- Introdução de:
  - Herança
  - Polimorfismo
  - Melhoria na hierarquia de classes
- Melhor organização e reaproveitamento de código

**Tecnologias:**
- Java (POO com Herança)

---

### 🔹 Fase 4 – Arquitetura DAO
**Pasta:** `fase4-DAO`

- Backend estruturado utilizando o **padrão DAO (Data Access Object)**
- Separação clara de responsabilidades entre:
  - Lógica de negócio
  - Camada de persistência de dados
- Integração com **Banco de Dados Oracle** para armazenamento de dados

**Conceitos Aplicados:**
- Padrão DAO  
- JDBC  
- SQL  
- Oracle Database  

**Tecnologias:**
- Java
- Oracle Database

---

### 🔹 Projeto Final – Aplicação Full Stack
**Pasta:** `final-project`

- Aplicação fintech completa
- Backend desenvolvido com **Spring Boot**
- Frontend desenvolvido com **Next.js**
- Comunicação via API REST entre frontend e backend
- Armazenamento persistente de dados utilizando **Oracle Database**

**Tecnologias:**
- Java
- Spring Boot
- Next.js
- API REST
- Oracle Database
