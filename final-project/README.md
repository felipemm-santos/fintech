# 💳 Fintech

Plataforma desenvolvida com arquitetura **Front-end + Back-end** para simular e gerenciar operações financeiras.  
O projeto foi criado com foco em **aprendizado**, **boas práticas** e **integração entre tecnologias modernas**.

---

## 🚀 Tecnologias Utilizadas

**Backend:** Java + Spring Boot  
**Frontend:** React + Vite + TypeScript  
**Gerenciador de Pacotes:** npm

---

## ⚙️ Como Executar o Projeto

### 🧩 Backend

1. Abra o projeto **no IntelliJ IDEA** (ou outra IDE compatível com Java/Spring).
2. Localize o arquivo principal:
   ```
   src/main/java/.../BackendApplication.java
   ```
3. Execute o arquivo para iniciar o servidor back-end.

---

### 💻 Frontend

1. No diretório do projeto front-end, instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. O front-end será executado em:
   ```
   http://localhost:3000/
   ```

---

## 🌐 Acesso à Aplicação

Após iniciar **ambos os servidores** (frontend e backend),  
acesse no navegador:

👉 **[http://localhost:3000/](http://localhost:3000/)**

## 🧠 Observações Importantes

- Certifique-se de que o **Java SDK** e o **Node.js** estão corretamente instalados.
- Inicie primeiro o **Back-end**, depois o **Front-end**.
- Se modificar as portas padrão, ajuste as configurações de proxy/endpoints no front.
